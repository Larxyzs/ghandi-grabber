# Ghandi Product Grabber

Chrome extension for ghandihomeelectro.com: finds products on brand websites (Whirlpool, LG, Candy, TCL,
Samsung, Haier, Bosch Morocco), grabs name, price, pictures and specifications, and sends them to the site.

Installed copies update themselves from this repository (see `RELEASING.md` and `updater/updater.js`).
Read `READ-ME-FIRST.txt` for how to use it.
